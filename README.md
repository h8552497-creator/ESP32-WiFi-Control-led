# ESP32-WiFi-Control-led

Control LEDs wirelessly using an ESP32 and a web-based dashboard. This project allows users to turn LEDs ON/OFF from any device connected to the same Wi-Fi network through a simple and responsive browser interface. Perfect for beginners learning IoT, ESP32 web servers, and smart home automation. Inspired by common ESP32 web-controlled LED projects
